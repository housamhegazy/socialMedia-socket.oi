📌 README for Social Media App
🧩 Project Overview

This is a full-stack Social Media application built with modern web technologies.
The project allows users to create posts, like them, comment, upload images, follow other users, chat, and receive real-time notifications.
It includes full authentication, social login with Google/Facebook/Twitter, and uses Cloudinary for image storage.

🚀 Tech Stack
Frontend

React

Material-UI (MUI)

Redux Toolkit + RTK Query

React Router

Socket.io Client

Backend

Node.js

Express.js

Mongoose (MongoDB)

JWT Authentication

Passport.js (Google, Facebook, Twitter Login)

Socket.io

Cloudinary for image hosting

🔐 Authentication Features

JWT-based authentication

Social login: Google, Facebook, Twitter

Protected routes for authenticated users

Auto-redirect on logout

User sessions stored securely

🖼️ Media Features

Upload images using Cloudinary

Compress images before upload (optional)

Delete images from Cloudinary

Support for profile pictures, cover photos, and post images

🧵 Social Features

Create posts (text + images)

Edit and delete posts

Like / Unlike posts

Add comments and delete comments

Follow / Unfollow users

User profile page with full details

Explore page to discover other users

💬 Real-Time Features (Socket.io)

Real-time chat between users

Online/offline user status

Real-time notifications for:

Likes

Comments

New followers

Messages
